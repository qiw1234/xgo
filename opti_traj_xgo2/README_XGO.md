# XGO机器人运动学库和步态生成

本目录包含了针对XGO机器人的运动学建模和步态生成代码，基于原有的GO2机器人代码改进而来。

## 文件说明

### 主要代码文件

1. **xgo_utils.py** - XGO机器人运动学工具库
   - 包含XGO机器人的运动学参数（从URDF文件提取）
   - 实现正运动学和逆运动学计算
   - 提供各种坐标变换函数

2. **xgo_trot.py** - XGO机器人步态生成程序
   - 使用CPG（中央模式生成器）生成trot步态
   - 计算足端轨迹和关节角度序列
   - 生成完整的机器人运动轨迹

### 运动学参数（从URDF提取）

XGO机器人的主要几何参数：
- 前后腿距离：0.14975 m
- 左右腿距离：0.0446 m  
- 大腿长度：0.0595 m
- 小腿长度：0.0715 m
- 典型机身高度：0.15 m

### 关节限制

各关节的运动范围：
- Hip关节（绕x轴）：[-0.8, 0.8] rad
- Thigh关节（绕y轴）：[-2.0, 2.0] rad
- Calf关节（绕y轴）：[-2.69, -0.9] rad

### 输出文件

运行`xgo_trot.py`后会生成：

1. **output/xgo_trot.txt** - 轨迹数据文本文件
   - 包含99帧轨迹数据（每帧49个数据点）
   - 数据格式：位置、姿态、速度、足端位置、关节角度等

2. **output_json/xgo_trot.json** - JSON格式轨迹文件
   - 结构化的轨迹数据
   - 包含帧时长和所有轨迹点信息

## 使用方法

### 1. 安装依赖
```bash
pip install casadi numpy matplotlib
```

### 2. 运行运动学测试
```bash
python xgo_utils.py
```

### 3. 生成步态轨迹
```bash
python xgo_trot.py
```

## 主要改进

相比于原始的GO2代码，针对XGO机器人的主要改进包括：

1. **运动学参数调整**
   - 根据XGO的URDF文件提取准确的几何参数
   - 调整关节限制范围
   - 适配XGO的机身尺寸

2. **步态参数优化**
   - 降低前进速度（0.3 m/s vs 0.5 m/s）
   - 减小抬腿高度（0.05 m vs 0.08 m）
   - 调整机身高度（0.15 m vs 0.28 m）

3. **增强的输出信息**
   - 添加详细的进度提示
   - 提供轨迹统计信息
   - 显示关节角度范围

## 技术细节

### 运动学建模
- 使用齐次变换矩阵描述各关节关系
- 支持正运动学和逆运动学求解
- 考虑机身姿态的运动学计算

### 步态生成
- 基于Hopf振荡器的CPG模型
- Trot步态（对角步态）
- 平滑的足端轨迹规划

### 优化求解
- 使用CasADi进行符号计算
- IPOPT求解器进行非线性优化
- 关节限制约束处理

## 输出数据格式

每一帧的49个数据点包括：
- [0:3] - 机身位置 (x, y, z)
- [3:7] - 机身姿态四元数 (x, y, z, w)
- [7:10] - 机身线速度 (vx, vy, vz)
- [10:13] - 机身角速度 (wx, wy, wz)
- [13:25] - 四条腿足端位置 (每腿3个坐标)
- [25:37] - 十二个关节角度
- [37:49] - 十二个关节角速度
